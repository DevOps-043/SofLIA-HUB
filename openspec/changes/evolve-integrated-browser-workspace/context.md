# Contexto del cambio

- Objetivo: evolucionar el navegador integrado a un workspace colaborativo tipo Codex, con navegador lateral derecho redimensionable, chat compacto de SofLIA en la columna izquierda, historial persistente, bóveda local de credenciales y extensiones compatibles administradas.
- Usuario o actor: usuario autenticado de la aplicación desktop y agente de escritorio autorizado mediante Computer Use.
- Alcance: modo navegador sobre el workspace existente; ancho persistente entre un mínimo utilizable y el ancho total del chat; reemplazo temporal del contenido de la Sidebar por un chat compacto mientras el navegador está abierto; historial local consultable y borrable; credenciales por origen cifradas con `safeStorage`; importación explícita de extensiones desempaquetadas compatibles con Electron.
- No objetivos: Chrome Web Store, archivos `.crx`, compatibilidad total con Chrome, sincronización cloud de historial/contraseñas/extensiones, captura automática de formularios, llenado silencioso por el agente, exponer secretos al modelo, múltiples pestañas o reemplazar el gestor de contraseñas del sistema.
- Restricciones: conservar `WebContentsView`, sandbox, partición persistente, separación main/preload/renderer, UI y logs en español, sin dependencia nueva; extensiones solo en sesión persistente y con subconjunto de APIs Electron; la bóveda falla cerrada si el cifrado del SO no está disponible.
- Contratos afectados: layout React, preferencias locales del panel, servicio `IntegratedBrowserService`, stores main de historial/credenciales/extensiones, diálogo nativo de instalación, canales `integrated-browser:*`, allowlist/preload, wrapper renderer, mocks, pruebas, documentación de arquitectura/seguridad/UX y OpenSpec.
- Riesgo y HITL: contraseñas y contenido web son secretos; guardar, rellenar, eliminar credenciales e instalar/remover extensiones requieren gesto explícito del usuario. La instalación muestra identidad, ruta y permisos declarados. El agente no recibe operaciones de bóveda ni extensión. Historial no registra `data:`, `file:`, credenciales URL ni páginas internas.
- Criterios verificables: el panel se abre a la derecha sin reemplazar el chat, se redimensiona y puede cubrir el chat central; la columna izquierda muestra un chat compacto y restaura la Sidebar al cerrar; historial sobrevive reinicio y tiene límite; el renderer nunca recibe una contraseña almacenada; autofill exige origen coincidente y gesto explícito; extensión inválida/peligrosa se rechaza; extensión aprobada se recarga al reinicio; IPC inválido o sender ajeno se rechaza; cierre libera listeners y vistas.
- Incertidumbres: se interpreta "el panel lateral izquierdo se convierte en chat" como un modo temporal exclusivo del navegador; el chat compacto reutiliza la conversación activa y las capacidades del agente, mientras el listado de chats/carpetas reaparece al cerrar. Las extensiones compatibles se limitan a carpetas desempaquetadas porque Electron no soporta Chrome Web Store ni `.crx`.
