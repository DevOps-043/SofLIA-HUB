# Contexto del cambio
- Objetivo: pasar del prototipo a colaboración verificable y preparación de integración audiovisual.
- Usuario o actor: instructor autorizado y participante asignado a un curso.
- Alcance: Hub y backend Learning; contrato de publicación Engine.
- No objetivos: modificar credenciales, aplicar SQL remoto, desplegar, inferir emociones o automatizar Zoom desde agentes.
- Restricciones: preservar diseño, español, cuatro capas IPC, consentimiento IA y autoridad académica.
- Contratos afectados: HTTP studio, IPC studio/watch/Zoom, manifiesto Engine, estado Realtime y persistencia SOFIA.
- Riesgo y HITL: acceso a medios y datos privados; aplicar migración/configurar producción requiere autorización final concreta.
- Criterios verificables: negativos de permisos, concurrencia/idempotencia, aislamiento de salas, cierre de recursos y ausencia de datos ficticios.
- Incertidumbres: credenciales SDK y publicación de manifiestos Engine aún no configuradas; no deben ocultarse como conexiones exitosas.
