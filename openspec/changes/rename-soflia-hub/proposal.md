## Why

El usuario cambia el nombre público de Pulse Hub a Soflia Hub y proporciona el
logo transparente y el icono de SofLIA Learning para sustituir la marca anterior.

## What Changes

- Sustituir el logo en todas las superficies existentes y generar iconos cuadrados.
- Renombrar textos, prompts, metadatos, instaladores, artefactos y documentación vigente.
- Conservar perfiles, cookies, cifrado, contratos SSO y actualizaciones existentes.
- No objetivos: publicación, instalación, cambios de dominios, credenciales o datos remotos.

## Capabilities

### New Capabilities

- `application-brand`: identidad pública coherente y compatibilidad de perfiles.

### Modified Capabilities

Ninguna; los contratos externos y de persistencia conservan sus identificadores.

## Impact

Renderer, textos Electron, arranque, recursos gráficos, shell Windows y workflow
de release. Sin dependencias nuevas, cambios IPC ni migraciones de base de datos.
