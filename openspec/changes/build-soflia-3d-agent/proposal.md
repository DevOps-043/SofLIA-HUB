# Agente visual tridimensional SofLIA

## Why
La identidad aprobada existe como imágenes. Hace falta un modelo editable real,
seis animaciones y una integración verificable sin alterar conversaciones existentes.

## What Changes
- Generador procedural Blender, logotipo vectorizado desde el original y GLB.
- Exportaciones PNG, GIF y WebM con validación de alfa y estructura.
- Controlador Three.js, componente React optativo y visor local independiente.
- Mediciones reproducibles y documentación del entorno y límites visuales.

## Impact
Capacidad nueva `soflia-visual-agent`. Sin IPC, persistencia ni cambios a agentes runtime.
Los binarios solicitados son entregables locales reproducibles, excluidos de Git.
