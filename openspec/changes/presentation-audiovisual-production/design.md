# Diseño

El contrato film.json solo contiene datos validados; el modelo no aporta código, ejecutables ni rutas absolutas. Una función SVG pura define cada frame y también alimenta la vista previa. Sharp rasteriza y FFmpeg recibe PNG por pipe con backpressure. Main conserva la propiedad de los binarios y aplica cuotas. El informe QA vincula los hashes del manifiesto y del MP4: editar las escenas invalida la entrega anterior.

Las operaciones render/cancel/export-pptx atraviesan servicio, handler validado, allowlist, preload y wrapper tipado. Solo el workspace activo del chat llega a la herramienta audiovisual; los canales de mensajería no la reciben. Hay una producción simultánea y un límite de doce minutos.

PPTX usa el mismo exportador en chat, create_document y equipos. Se conservan los contratos antiguos de título/cuerpo y el PDF explícito. El HTML declarativo incrusta un IIFE con sus dependencias; no incorpora el bundle de la aplicación.

La configuración audiovisual tiene archivo separado e ignorado. No se lee ni modifica el .env existente. No se crean secretos. El runtime de medios se instala explícitamente para el equipo local; su redistribución requiere incorporar licencias y el runtime correspondiente a cada plataforma.
