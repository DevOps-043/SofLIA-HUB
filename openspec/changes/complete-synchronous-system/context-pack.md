# Contexto del cambio

- Objetivo: cerrar las brechas de código del diagnóstico de sesiones síncronas.
- Actor: instructor, participante y autor autorizado de Engine.
- Alcance: participación Learning, entrega de preparación, salas audiovisuales, composición y diagnóstico verificable.
- No objetivos: compra de capacidad, activación remota, publicación de cursos reales, promesas de concurrencia sin medición.
- Restricciones: aislamiento académico, SDK público, español, compatibilidad Meeting, secretos solo servidor.
- Contratos: studio, manifiesto Engine, operaciones HTTP autenticadas y bridge audiovisual aislado.
- Riesgo y HITL: no ejecutar SQL remoto ni enviar contenido real durante las pruebas.
- Aceptación: autorización denegada, duplicados, relojes, formato legacy y versiones cruzadas cubiertos por pruebas.
- Incertidumbres: capacidades reales de la cuenta y multimedia de larga duración se confirman en piloto.
