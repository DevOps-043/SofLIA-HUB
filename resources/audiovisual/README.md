# Recursos audiovisuales

Fuentes locales para el reproductor y las capturas sin red. Inter Display y
JetBrains Mono proceden del proyecto de referencia aportado por el usuario,
con sus licencias OFL conservadas en `fonts/`. No se requiere instalarlas en el
sistema operativo. Se incorporan como datos al HTML aislado y al instalador.

`soflia-logo-geometry.json` conserva la geometría de ocho nodos y enlaces del
símbolo de la referencia SofLIA aportada por el usuario. No corresponde al icono
horizontal de cuatro nodos de otros assets del producto. Sólo se utiliza cuando
el manifiesto identifica explícitamente esa marca; otras marcas usan tipografía.
La comparación de la referencia es evidencia geométrica, no autorización para
declarar una identidad oficial distinta ni atribución a una API privada.
