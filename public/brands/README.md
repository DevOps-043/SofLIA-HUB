# Marcas de almacenamiento

Recursos oficiales sin modificar, descargados el 2026-10-24 para identificar las integraciones. No se solicitan imágenes a terceros durante el uso de la aplicación.

- Google Drive: [recurso oficial](https://www.gstatic.com/images/branding/productlogos/drive_2026/v2/web-64dp/logo_drive_2026_color_2x_web_64dp.png), según las [indicaciones de Google](https://developers.google.com/workspace/drive/api/guides/branding).
- OneDrive: [SVG oficial](https://adoption.microsoft.com/wp-content/uploads/2025/10/icon-onedrive.svg), publicado en [Microsoft Adoption](https://adoption.microsoft.com/en-us/onedrive/).

Las marcas pertenecen a Google y Microsoft, respectivamente. Su presencia identifica el proveedor vinculado.
